**QUADRO 3**

**Informação título a título exigida**

Os dados relativos aos campos do quadro seguinte devem ser reportados relativamente a cada título classificado nas categorias «títulos de dívida», «títulos de participação no capital» e «ações/unidades de participação de FI», nos quadros 1 e 2, de acordo com as regras seguintes.

1. Devem ser reportados dados para preenchimento do campo 1. Se um título tiver código ISIN, este deve ser reportado.

2. Se o BCN competente não compilar diretamente a informação sobre operações título a título, devem ser reportados dados para dois dos três campos seguintes: 2, 3 e 4 (ou seja, para os campos 2 e 3, campos 2 e 4 ou campos 3 e 4).

3. Se o BCN competente recolher informação direta sobre operações título a título, devem ser reportados dados para os seguintes campos:

a) campo 5, ou campos 6 e 7; e

b) campo 4, ou campos 2 e 3.

4. O BCN competente pode ainda exigir aos FI que reportem dados para o campo 8.

5. O BCN competente pode optar por só recolher dados para o campo 2 no n.º 2 e no n.º 3, alínea b).

6. Além disso, para cada título sem código ISIN ou outro código de identificação válido de acordo com as instruções do BCN competente, devem ser reportados dados de acordo com as regras seguintes.

a) Devem ser reportados dados para os campos 9 e 10. Se o emitente do valor mobiliário tiver um Identificador de Entidade Jurídica (LEI), este deve ser comunicado.

b) Devem ser reportados dados para os campos 11, 12 e 13. O BCN competente pode optar por não recolher estes dados se os dados reportados para o campo 10 forem um LEI, um código de identificação nacional especificado no sítio Web do BCE ou outro código de identificação que o BCE considere válido.

c) Para cada título classificado na categoria «títulos de dívida», devem ser reportados os dados relativos aos campos 14, 15 e 16. O BCN competente pode optar por não recolher dados para o campo 16 se os puder derivar de outros dados recolhidos utilizando uma metodologia previamente acordada com o BCE.
